    この　店の　開店は　十時です。

    1. がいてん
    2. かいてん
    3. かいってん
    4. かいでん

  2. 問題2　＿＿＿の　ことばは　どう　書きますか。1・2・3・4から　いちばん　いい　ものを　一つ　えらんで　ください。

    ひるまは　仕事で　家に　いません。

    1. 昼問
    2. 書間
    3. 昼間
    4. 昼閉

  3. 問題3　（　　）に　何を　入れますか。1・2・3・4から　いちばん　いい　ものを　一つ　えらんで　ください。

    この　字は　（　　）　ので　もう　一度　書いて　ください。

    1. ふとい
    2. きたない
    3. おおきい
    4. うつくしい

  4. 問題4　＿＿＿の　文と　だいたい　同じ　意味の　文が　あります。1・2・3・4から　いちばん　いい　ものを　一つ　えらんで　ください。
