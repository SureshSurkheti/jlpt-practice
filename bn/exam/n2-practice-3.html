উত্তর ছাড়া চারটি প্রশ্ন। সময় ধরে ও স্বয়ংক্রিয় মূল্যায়নসহ সবগুলো করতে পেপারটি শুরু করুন।

  1. 問題1　＿＿＿の言葉の読み方として最もよいものを、1・2・3・4から一つ選びなさい。

    血液の循環をよくする運動だ。

    1. しゅんかん
    2. じゅんかん
    3. じゅんがん
    4. じゅかん

  2. 問題2　＿＿＿の言葉を漢字で書くとき、最もよいものを、1・2・3・4から一つ選びなさい。

    国のとうけいによると人口は減っている。

    1. 統言
    2. 統話
    3. 統針
    4. 統計

  3. 問題3　（　　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。

    この薬は子ども（　　）に作られている。

    1. あて
    2. 向け
    3. つき
    4. 行き

  4. 問題4　（　　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。

    その説明では（　　）がいかない。

    1. 承知
    2. 了解
    3. 承認
    4. 納得
