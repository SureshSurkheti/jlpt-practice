N5 Tata bahasa

Seluruh kosakata JLPT dari N5 sampai N1 dengan cara baca dan arti, plus pola tata bahasa inti tiap level. Cari dalam bahasa Jepang, romaji, atau Inggris.

52 pola

PolaArtiContoh
ですis / am / areहो / हुँ私は学生です。I am a student.
じゃありませんis not (polite)होइन私は学生じゃありません。I am not a student.
〜は〜ですtopic marker はविषय जनाउने はこれは本です。This is a book.
〜がsubject marker がकर्ता जनाउने が猫がいます。There is a cat.
〜をdirect object marker をकर्म जनाउने をご飯を食べます。I eat rice.
〜に (time)at (a point in time)समयमा七時に起きます。I get up at seven.
〜に (direction)to (a destination)तिर / मा学校に行きます。I go to school.
〜で (place)at / in (where an action happens)मा (काम हुने ठाउँ)図書館で勉強します。I study at the library.
〜で (means)by / with (a means)बाट / लेバスで行きます。I go by bus.
〜とand / withर / सँग友達と話します。I talk with a friend.
〜から〜までfrom ... to ...देखि ... सम्म九時から五時まで働きます。I work from nine to five.
〜ませんかwon't you ...? (invitation)गर्नुहुन्न ?一緒に行きませんか。Won't you come along?
〜たいwant to ...गर्न चाहन्छु水が飲みたいです。I want to drink water.
〜ないでくださいplease don't ...नगर्नुहोस्写真を撮らないでください。Please don't take photos.
〜てくださいplease do ...गर्नुहोस्ここに書いてください。Please write here.
〜ているis ...ing / stateगर्दैछु今、食べています。I am eating now.
〜てもいいですmay / it's fine to ...गरे पनि हुन्छ入ってもいいですか。May I come in?
〜てはいけませんmust not ...गर्नु हुँदैनここで遊んではいけません。You must not play here.
〜なければなりませんmust / have to ...गर्नैपर्छ薬を飲まなければなりません。I have to take medicine.
〜ことができるcan / be able toगर्न सक्छु日本語を話すことができます。I can speak Japanese.
〜が好きですlike ...मन पर्छ音楽が好きです。I like music.
〜が上手ですbe good at ...राम्रो छ彼は料理が上手です。He is good at cooking.
〜より〜のほうが... is more ... thanभन्दा बढी電車のほうが速いです。The train is faster.
〜のなかで一番the most ... amongमध्ये सबैभन्दा果物の中でりんごが一番好きです。Among fruits I like apples best.
〜たことがあるhave done ... beforeगरेको छु日本に行ったことがあります。I have been to Japan.
〜ながらwhile doing ...गर्दै音楽を聞きながら勉強します。I study while listening to music.
〜前にbefore ...अघि寝る前に歯を磨きます。I brush my teeth before sleeping.
〜あとでafter ...पछि食事のあとで散歩します。I walk after the meal.
〜ときwhen ...बेला子供のとき、よく遊びました。When I was a child I played a lot.
〜のでbecause (soft)किनभने寒いので、窓を閉めます。It's cold, so I'll close the window.
〜から (reason)becauseकिनभने忙しいから、行けません。I can't go because I'm busy.
〜が (but)butतर高いですが、いいです。It's expensive, but it's good.
〜でもbut / howeverतर पनि雨です。でも、行きます。It's raining. But I'll go.
〜もうalreadyपहिले नैもう食べました。I have already eaten.
〜まだnot yet / stillअझैまだ食べていません。I haven't eaten yet.
〜ぐらいabout (quantity)लगभग一時間ぐらいかかります。It takes about an hour.
〜だけonlyमात्र水だけ飲みます。I drink only water.
〜しか〜ないonly (nothing but)बाहेक केही छैन百円しかありません。I only have a hundred yen.
〜や〜などthings like ... and ...आदि本や雑誌などを買いました。I bought books, magazines and so on.
〜というcalled / namedभनिनेこれは何といいますか。What is this called?
〜になるbecomeबन्नु医者になりたいです。I want to become a doctor.
〜くする / 〜にするmake it ...बनाउनु部屋をきれいにします。I'll make the room clean.
〜つもりですintend to ...गर्ने विचार छ来年、日本へ行くつもりです。I intend to go to Japan next year.
〜でしょうprobably / right?होला明日は雨でしょう。It will probably rain tomorrow.
〜たり〜たりするdo things like ... and ...गर्नु आदि週末は読んだり書いたりします。At weekends I read, write and so on.
〜ほうがいいhad better ...गरे राम्रो早く寝たほうがいいです。You had better sleep early.
〜すぎるtoo much ...धेरै भयो食べすぎました。I ate too much.
〜やすい / 〜にくいeasy / hard to ...सजिलो / गाह्रोこの本は読みやすいです。This book is easy to read.
〜ましょうかshall I ...?गरौं कि ?窓を開けましょうか。Shall I open the window?
〜がある / 〜がいるthere is (thing / living)छ公園に犬がいます。There is a dog in the park.
〜もalso / tooपनि私も行きます。I will go too.
〜ね / 〜よright? / you knowहैन र ? / निいい天気ですね。Nice weather, isn't it?
