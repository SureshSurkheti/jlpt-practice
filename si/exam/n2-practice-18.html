මෙම ප්‍රශ්න පත්‍රයේ ප්‍රශ්න කිහිපයක්

පිළිතුරු නොමැතිව ප්‍රශ්න හතරක්. සියල්ල කාලය සමඟ හා ලකුණු කිරීම සමඟ කිරීමට ප්‍රශ්න පත්‍රය ආරම්භ කරන්න.

  1. 問題1　＿＿＿の言葉の読み方として最もよいものを、1・2・3・4から一つ選びなさい。

    制度の改革が急がれている。

    1. がいかく
    2. かいかく
    3. かいかぐ
    4. かいがく

  2. 問題2　＿＿＿の言葉を漢字で書くとき、最もよいものを、1・2・3・4から一つ選びなさい。

    薬のこうかが現れてきた。

    1. 効果
    2. 効束
    3. 効東
    4. 父果

  3. 問題3　（　　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。

    雨（　　）で試合が中止になった。

    1. 空
    2. 天
    3. 模
    4. 候

  4. 問題4　（　　）に入れるのに最もよいものを、1・2・3・4から一つ選びなさい。

    損害を（　　）うよう求められた。

    1. 払
    2. 補
    3. 報
    4. 償
